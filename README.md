# ocal-checker

根据 OCAL 屏幕截图，自动分析牛反光轴问题，给出诊断和修正建议。

## 安装
```bash
cd /Users/xlisp/PyPro/ocal-checker
pip install -r requirements.txt
```

## 用法
```bash
# 1. 自动分析一张截图
python ocal_checker.py shot.png

# 2. 指定主镜中心标记的位置（截图像素坐标，用预览软件看坐标）
python ocal_checker.py shot.png --primary 945 598

# 3. 弹窗用鼠标点：先点主镜中心标记，再沿副镜真实边缘点 6~12 个点，回车结束
python ocal_checker.py shot.png --pick

# 4. 监视截图目录，每来一张新截图就分析并弹 macOS 通知
python ocal_checker.py --watch ~/Desktop --notify
```

输出：终端诊断报告 + `xxx_analysis.png` 标注图（白圈=拟合圆，黄十字=绿圈圆心，青十字=蓝圈圆心，黄椭圆=副镜边缘，橙箭头=主镜中心→准星）。

## 参数
| 参数 | 说明 |
|---|---|
| `--r1 / --r3` | OCAL 里圈1(绿)、圈3(蓝)的半径数值，默认 270 / 349，用于换算圆心偏移量 |
| `--axis-angle` | 镜筒轴向在画面里的方向(度，0=向右，90=向上)，默认 90。决定“轴向/横向”偏差的拆分 |
| `--green-rgb / --blue-rgb / --cross-rgb` | OCAL 里改过颜色时用，如 `--green-rgb 0,255,0` |
| `--tol` | 颜色匹配容差，默认 60 |
| `--no-ellipse` | 跳过自动椭圆检测 |

## 判断逻辑（对应排查顺序）
1. **基准**：准星中心 vs 蓝圈圆心 → 相机/接口不同心，用「启用圆心偏移」修。
2. **副镜轴向位置**：绿圈相对蓝圈沿轴向的偏差 → 前后/高度。
3. **副镜旋转/横向**：垂直轴向的偏差 → 旋转或支架中心偏离镜筒轴线。
4. **椭圆度**：沿绿圈附近找副镜真实边缘拟合椭圆 → 45° 角、支架水平、调焦座垂直度。
5. **主镜中心 vs 准星**：副镜倾斜螺丝该往哪个方向调。
6. **“二选一”特征**：主镜中心偏 + (不同心 或 椭圆) 同时出现 → 提示查调焦座垂直度、三臂支架高度、副镜安装面角度，并给出垫片修正办法。

## 注意
- 阈值写在文件开头（`TOL_*`、`ELL_*`、`PRI_*`），可按自己的镜子调整。
- 自动检测副镜边缘依赖画面对比度；检测不稳时用 `--pick` 手点。
- 广角镜头在画面边缘有畸变，椭圆度要结合“相机转 90° 看椭圆是否跟着转”来判断。
- 截图要包含完整的相机画面和三个圈、准星；控制面板可以留在截图里，程序只在准星范围内找圈。
