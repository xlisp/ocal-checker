# ocal-checker

根据 OCAL 屏幕截图，自动分析牛反光轴问题，给出诊断和修正建议。

## 安装
```bash
cd /Users/xlisp/PyPro/ocal-checker
pip install -r requirements.txt
```

## 用法
```bash
python ocal_checker.py shot.png                     # 自动分析
python ocal_checker.py shot.png --primary 945 598   # 指定主镜中心标记坐标(截图像素)
python ocal_checker.py shot.png --pick              # 弹窗手点：主镜中心 → 副镜边缘 → 调焦座边缘
python ocal_checker.py --watch ~/Desktop --notify   # 监视截图目录，新截图自动分析并弹 macOS 通知
```

输出终端诊断报告 + `xxx_analysis.png` 标注图（黄=副镜椭圆，青=调焦座椭圆，橙箭头=主镜中心→准星）。

## v2 测量原理
OCAL 的绿/蓝/红圈共用同一个圆心，互相比较永远同心，所以**只把它们当定位参考**，真正测量的是画面里的真实物体：

1. 真实调焦座内壁边缘（蓝圈附近）→ 拟合椭圆 = 基准中心
2. 真实副镜边缘（绿圈附近）→ 拟合椭圆
3. 主镜中心标记（需 `--primary` 或 `--pick`）

再比较：
- 准星中心 vs 调焦座中心 → 相机/接口是否同心
- 副镜中心 vs 调焦座中心 → 轴向（前后/高度）与横向（旋转/支架偏移）
- 副镜椭圆度 − 调焦座椭圆度（同向时扣除）→ 排除镜头畸变后的净椭圆度
- 主镜中心 vs 准星 → 倾斜方向
- 主镜中心偏 + (位置偏 或 椭圆) → “二选一”特征，提示查调焦座垂直度、三臂支架高度、安装面 45° 角

## 参数
| 参数 | 说明 |
|---|---|
| `--r1 / --r3` | OCAL 圈1(绿)、圈3(蓝)的半径数值，默认 270 / 349 |
| `--axis-angle` | 镜筒轴向在画面里的方向(度，0=向右，90=向上)，默认 90，决定轴向/横向的拆分 |
| `--green-rgb / --blue-rgb / --cross-rgb` | OCAL 里改过颜色时使用，如 `--green-rgb 0,255,0` |
| `--tol` | 颜色匹配容差，默认 60 |
| `--no-ellipse` | 跳过自动边缘检测 |

## 注意
- 自动边缘检测精度大约 ±2% 调焦座半径（合成图测试），低对比度时更差；关键判断请用 `--pick` 手点复核。
- 阈值写在文件开头（`TOL_*`、`ELL_*`、`PRI_*`），可按自己的镜子调整。
- 截图要包含完整的相机画面、三个圈和准星；控制面板可以留在截图里。
